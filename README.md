# OmniAgent

An LLM-Powered Omni-Agent with Persistent Agentic Memory using CockroachDB and AWS.

## Project Goal

Build an AI agent that can remember user information across sessions, retrieve relevant memories, and provide personalized responses.

## Core Technologies

- Python
- FastAPI
- React
- Amazon Bedrock
- CockroachDB
- Vector Search
- MCP
- AWS
